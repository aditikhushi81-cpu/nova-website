# NOVA® — Digital Experience Studio

A multi-page website for a fictional digital studio, built for my CodSoft
internship (Task 02). All studio names, projects and copy are concept content.

**Live demo:** https://aditikhushi81-cpu.github.io/nova-website/


## Pages
- **Home:** hero, studio statement, capabilities, selected work, manifesto, call to action
- **Work:** project showcase with alternating layouts and a capabilities list
- **About:** approach, process hover list, principles, sliding statement
- **Contact:** project inquiry form that emails the studio

## Features
- Scroll-based animations with GSAP and ScrollTrigger
- Sequential text and image reveals, plus parallax images
- Interactive full-screen navigation menu
- Page loader with progress counter
- Project-focused Work section with image-driven presentation
- Structured About and Contact pages with a working contact form
- Responsive layouts across screen sizes

## Tech
HTML5 • CSS3 • JavaScript • GSAP • GSAP ScrollTrigger • Responsive Web Design

## Project structure
    nova/
    ├── index.html, work.html, about.html, contact.html
    ├── css/  (style.css + one stylesheet per page)
    ├── js/   (menu.js, script.js + one script per page)
    └── pictures/

## Run locally
Open the folder in VS Code and start it with the Live Server extension ("Go Live").
